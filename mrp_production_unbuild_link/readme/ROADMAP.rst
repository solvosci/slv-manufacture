This addon limits number of times a MO could be unbuilt to once. This is not exact,
because e.g. a MO that will be used to produce 10 units could be partially unbuilt.

Then, this addon should be improved in this way:

* Enable more than one unbuilds linked to a MO (Many2one -> Many2many).
* Replace control for more than one unbuild to a more detailed total quantity in
  unbuilds versus total quantity produced for the MO.
