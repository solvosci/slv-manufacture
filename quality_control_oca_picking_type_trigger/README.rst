Known issues / Roadmap
======================

* Feature added by this module could be added as IMP to current OCA's
  `quality_control_stock_oca` addon.
* At picking type form, adding a test trigger could be improved, because trigger
  field can be directly obtained from current picking type (it should be
  the trigger that is currently linked to that picking type) and shouldn't be
  changed at all.
